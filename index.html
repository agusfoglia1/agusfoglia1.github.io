Campus Inteligente

Sistema web para gestionar un campus y tomar asistencia por QR.

  • FastAPI
  • PostgreSQL
  • JWT
  • React
  • TypeScript
  • Vite
  • Tailwind CSS
  • Docker
  • El estudiante muestra un QR dinámico desde su celular y una cámara fija en la puerta del aula lo lee para registrar la asistencia.
  • Backend en Python con autenticación JWT y base de datos PostgreSQL.
  • Interfaz responsive, probada en un celular real, con foco en que se vea profesional y dinámica.

Basurero Inteligente

Proyecto de la materia IC I.

En desarrollo

  • ESP32
  • MicroPython
  • Sensor PIR
  • HC-SR04
  • Servomotor
  • MIT App Inventor
  • Basurero con un ESP32 que detecta presencia con un sensor PIR, mide el nivel de llenado con un sensor ultrasónico y mueve la tapa con un servomotor.
  • Programado en MicroPython, con control del servo por PWM.
  • La aplicación móvil se está desarrollando con MIT App Inventor.
